# Super Saver 🛒💰

En modern webbapplikation för att hitta de bästa erbjudandena i din närhet med realtidspositionering och interaktiva kartor.

## ✨ Funktioner

### 🗺️ Interaktiva kartor
- **Google Maps integration** med fallback till OpenStreetMap
- **Realtidspositionering** med navigator.geolocation
- **Manuella platsuppdateringar** genom klick på kartan
- **Specialmarkör** för användarens exakta position

### 🔍 Smart sökning
- **Platsbaserad sökning** med adress eller postnummer
- **Kategorifiltrering** (Mat, Kläder, Elektronik, Hem, Sport)
- **Automatisk sortering** efter bästa erbjudanden

### 💡 Erbjudanden
- **Realtidsavstånd** till varje erbjudande
- **Detaljerad information** om rabatter och priser
- **Klickbara kort** som visar platsen på kartan
- **Responsiv design** för alla enheter

### 🎨 Modern design
- **Glassmorfism-effekter** för modern look
- **Röd och vit färgpalett** för tydlig branding
- **Mobiloptimerad** interface
- **Smooth animationer** och övergångar

## 🚀 Kom igång

1. Öppna `index.html` i en webbläsare
2. Eller starta den lokala servern:
   ```powershell
   powershell -ExecutionPolicy Bypass -File server.ps1
   ```
3. Navigera till `http://localhost:8080`

## 📁 Projektstruktur

```
├── index.html      # Huvudsida med HTML-struktur
├── styles.css      # CSS-styling med glassmorfism
├── script.js       # JavaScript för kartor och funktionalitet
├── server.ps1      # PowerShell server för lokal utveckling
└── README.md       # Denna fil
```

## 🛠️ Teknologier

- **HTML5** - Semantisk struktur
- **CSS3** - Modern styling med glassmorfism
- **JavaScript ES6+** - Interaktiv funktionalitet
- **Google Maps API** - Kartfunktionalitet (med OpenStreetMap fallback)
- **Geolocation API** - Realtidspositionering
- **PowerShell** - Lokal utvecklingsserver
